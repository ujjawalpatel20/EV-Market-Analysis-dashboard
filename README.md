# EV-Market-Analysis-dashboard
Electric Vehicle Market Analysis Tableau.
This project analyzes Electric Vehicle (EV) market data using Tableau to understand vehicle distribution, manufacturers, battery capacity, and driving range.

Objectives

Analyze the number of electric vehicles in the dataset.
Compare EV manufacturers.
Explore battery capacity and driving range.
Understand EV distribution by manufacturing country.
Tools Used

Tableau Public
Microsoft Excel / CSV Dataset
GitHub
Key Performance Indicators

Total EV Records: 199,999
Average Battery Capacity: 78.24 kWh
Average Driving Range: 324.5 km
Visualizations

Conclusion

This dashboard provides an overview of electric vehicle market data and helps identify patterns in manufacturers, battery capacity, driving range, and manufacturing countries.
